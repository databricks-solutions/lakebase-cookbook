# Data

Examples for moving data between the lakehouse and Lakebase — online feature
serving and reverse ETL.

| Example | Description |
|---------|-------------|
| [`feature_store/`](feature_store/) | Serve features to models with low latency by syncing lakehouse tables into Lakebase. |
| [`reverse_etl/`](reverse_etl/) | Push analytical results back into Lakebase for low-latency serving to applications. |
